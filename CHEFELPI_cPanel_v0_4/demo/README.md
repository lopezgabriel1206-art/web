# Vista visual independiente (no es la aplicación)

Abrir `demo/index.html` desde un navegador para ver un **borrador visual de la portada** sin instalar dependencias. Los enlaces internos de esta vista apuntan a secciones del mismo archivo y NO sustituyen las rutas multipágina implementadas en `src/app`.

La plataforma real está en las carpetas `src/app`, `src/components` y `src/lib` y necesita instalar Node, Next.js y PostgreSQL para comprobarla.

Esta vista permite inspeccionar la combinación de colores y el emblema original antes de tener un servidor local; no demuestra que las funcionalidades conectadas a BD funcionen.
